## Example

```yaml
env:
  - name: POSH_THEME
    value: '{{ .Home }}/.configs/posh.omp.yaml'
```

## Description

Some fields have [text/template][go-text-template] abilities, allowing to reuse the same
configuration across multiple environments resulting in environment specific values.

Out of the box you get the following functionality:

### Variables

| Name | Type | Description |
| --- | --- | --- |
| `.Shell` | `string` | the current shell name |
| `.Home` | `string` | the user's `$HOME` folder |
| `.OS` | `string` | the current operating system |
| `.Arch` | `string` | the `aliae` executable architecture |
| `.AliaeConfig` | `string` | the resolved `aliae` configuration file path |
| `.AliaeConfigDir` | `string` | the directory of the resolved config file |

Variable examples:

- `.Shell`: `{{ .Shell }}`
- `.Home`: `{{ .Home }}/go/bin/aliae`
- `.OS`: `{{ if eq .OS "windows" }}.exe{{ end }}`
- `.Arch`: `{{ .Arch }}`
- `.AliaeConfig`: `{{ .AliaeConfig }}`
- `.AliaeConfigDir`: `{{ .AliaeConfigDir }}`

### Functions

| Name | Type | Description |
| --- | --- | --- |
| `env` | `string` | retrieve an environment variable value |
| `match` | `boolean` | match a shell name to one or multiple options |
| `hasCommand` | `boolean` | check if an executable exists |
| `homeFileExists` | `boolean` | check if a file exists relative to `.Home` by default |
| `homeDirExists` | `boolean` | check if a directory exists relative to `.Home` |

Function examples:

- `env`: `{{ env "POSH_THEME" }}`
- `match`: `{{ match .Shell "zsh" "bash" }}`
- `hasCommand`: `{{ hasCommand "oh-my-posh" }}`
- `homeFileExists`: `{{ homeFileExists ".cache/aliae" }}`
- `homeDirExists`: `{{ homeDirExists ".cache" }}`

`homeFileExists` and `homeDirExists` resolve paths relative to `.Home` unless the path is absolute.
Results are cached per resolved path during the current run.
If the same path is checked again later (for example from `script`),
the cached result is reused instead of checking the filesystem again.

:::tip
When using a template in a single line, you have to use quotes to wrap the template string.

```yaml
env:
  - name: POSH_THEME
    value: '{{ .Home }}/.configs/posh.omp.yaml'
```

:::

[go-text-template]: https://golang.org/pkg/text/template/
