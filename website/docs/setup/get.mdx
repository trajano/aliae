Use `aliae get` to read runtime values.

## Shell

Print the detected shell:

```bash
aliae get shell
```

## Debug shell detection

Use `aliae debug` to inspect shell detection layers (for example Scoop shims):

```bash
aliae debug
```

Debug output includes:

- executable name
- process layers (`layer 0`, `layer 1`, ...)
- shim detection hops
- final resolved shell
